# Lean-Project-lyyc
代码出自龙岩烟草工业有限责任公司卷包车间精益课题《智·精·准：DMAIC 框架下卷烟成本数据质量智能优化实践》

1、车间暂存区自动化跟踪对账
对龙烟卷包车间一、二区物流高架库消耗表的调整和筛选，自动化比对分析车间暂存区内所有辅料领退料数据的不平衡情况并标记异常值，为车间提供及时有效的数据纠偏依据。

2、NC 系统辅料高架库和物流辅料领退料记录对账
对导出的“高架库中间表”数据进行统一清洗、格式化及合并，随后与一区、二区的物流系统辅料领退料记录表进行精确匹配，输出疑似异常数据，并智能化判别该疑似异常数据是否为真实异常。

3、 车间辅料单耗自动化测算与历史值比对
对车间辅料消耗数据进行结构性清洗与归类处理，并融合真实历史消耗数据与烟用材料消耗记录，实现多源异构数据的统一对齐与折算逻辑校验。
